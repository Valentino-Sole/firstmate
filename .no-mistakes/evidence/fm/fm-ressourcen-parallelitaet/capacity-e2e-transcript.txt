

==================================================================
SZENE 1 - Hetzner-Server allein, keine Worker: was traegt der Host?
==================================================================
Vorgabe: der Hetzner-Server allein hoechstens drei Dauer-Worker.

$ fm-capacity.sh slots
slots=3
occupied=0
free=3
homes_scanned=1
nproc=16
mem_avail_mb=13312
load1=2.0
[exit 0]


==================================================================
SZENE 2 - Drei Dauer-Worker laufen: der vierte wird abgewiesen
==================================================================

$ fm-capacity.sh slots
slots=3
occupied=3
free=0
homes_scanned=1
nproc=16
mem_avail_mb=13312
load1=2.0
[exit 0]

-> ein vierter unabhaengiger Worker will starten:

$ fm-capacity.sh spawn-gate --task-id neue-aufgabe
error: capacity: no free worker slot (occupied=3 slots=3 homes_scanned=1); independent work waits until a live worker on this host finishes; running workers were left running
[exit 1]
-> und dieselbe Aufgabe ein zweites Mal (Beweis je Worker: eine Task-ID, ein Worker):

$ fm-capacity.sh spawn-gate --task-id jarvis-zentrale-kapazitaet
error: capacity: task jarvis-zentrale-kapazitaet already has a worker; sequential replacement uses relaunch, never a second concurrent worker
[exit 1]

-> die drei laufenden Worker wurden nicht angefasst:
fm-jarvis-zentrale-kapazitaet
fm-fm-ressourcen
fm-backlog-pflege

free=0
homes_scanned=1
nproc=16
mem_avail_mb=13312
load1=unavailable
[exit 0]

$ fm-capacity.sh spawn-gate --task-id neue-aufgabe
error: capacity: supervisor host is at measured capacity (slots=0 occupied=3 homes_scanned=1 nproc=16 load1=unavailable mem_avail_mb=13312); refusing a new independent worker rather than overloading this host
[exit 1]
-> die gescheiterte Messung bleibt sichtbar (load1=unavailable), nicht ein erfundenes 0.
   Kein Start auf einem ungemessenen Host.
